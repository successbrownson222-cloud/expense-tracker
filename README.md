# Python Expense Tracker 💰

A simple CLI expense tracker built with Python after completing the Learn Python course on Codeliber.

### What it does
- Add income (Salary, Freelance)
- Add expenses (Airtime, Food, Transport)
- Calculates final balance
- Shows transaction history

### Output
=== SUCCESS EXPENSE TRACKER ===
Income: N10000 - Salary
Income: N2000 - Freelance
Expense: N500 - Airtel Airtime
Expense: N1500 - Food
Expense: N700 - Transport

FINAL BALANCE: N9300

### How to run
1. Copy expense-tracker.py
2. Run with Python 3
